# v1.6.0

## 新功能

- **Swagger API 文档**：访问 `http://localhost:8080/swagger-ui.html`，支持 Bearer JWT 在线调试
- **生产安全告警**：启动时自动检测 JWT / HMAC / AES / 数据库密码是否为默认值
- **移动端适配**：管理后台侧栏改为移动端抽屉菜单；商城头部响应式优化

## 文档

- 新增 [docs/API.md](../API.md) API 使用说明
- 新增 [CONTRIBUTING.md](../../CONTRIBUTING.md) 贡献指南

## 升级说明

从 v1.5.x 升级无需执行额外数据库脚本，拉取最新代码后重新构建即可：

```bash
git pull origin main
docker compose up -d --build
```
