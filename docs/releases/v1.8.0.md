# v1.8.0 — 优惠券与营销促销

## 设计原则

- **单表**：促销活动与优惠券共用 `promotion` 表，通过 `kind`（`ACTIVITY` / `COUPON`）区分
- **商品范围**：`product_ids` 逗号分隔，空表示全场；不再使用关联表
- **用量统计**：优惠券使用量通过 `shop_order.promotion_id` 统计，无独立 usage 表
- **SQL**：结构定义集中在 `backend/src/main/resources/db/schema.sql`

## 新功能

- 管理后台「促销活动」：满减、折扣、特价/节日价
- 管理后台「优惠券」：发布券码、发行量、每人限用、限定商品
- 商城自动展示促销价，购买页支持优惠券预览与下单
- 支付成功后核销优惠券（`used_count + 1`）

## 数据库说明

`db/` 目录仅保留 `schema.sql` 一个文件；已删除 `data.sql` 与历史 `migration-v*.sql`。旧环境升级请对照 `schema.sql` 补全差异，或重建库。
