# v1.7.0

## 新功能

- **微信 JSAPI 支付**：在微信内置浏览器中自动 OAuth 获取 openid 并调起支付
- **单元测试**：`PaymentService`、`OrderService` 核心逻辑测试
- **Docker 健康检查**：Spring Actuator `/actuator/health`，前端等待后端就绪后启动
- **管理后台 i18n**：主导航、登录、Dashboard、产品/卡密/批次/订单等页面支持中英切换

## 配置说明

微信 JSAPI 需在支付配置中填写 **App Secret**（用于 OAuth），详见 [docs/PAYMENT.md](../PAYMENT.md)。

## 升级

```bash
git pull origin main
docker compose up -d --build
```
