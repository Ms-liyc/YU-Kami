## 安全

- 卡密哈希升级 **v3**：默认 **3 轮**链式 HMAC，每轮 HKDF 独立派生密钥
- 校验码同步升级 v3 多轮 HMAC（8 位），兼容 v1 六位 / v2 八位
- 元数据 `encrypted_meta` 与 Redis 订单缓存默认 **3 层** AES-256-GCM 加密
- 完全兼容 v1/v2 卡密兑换，以及 `enc:` 单层 Redis 缓存

## 配置

可通过环境变量调整加密强度（新卡密生效）：

```env
CRYPTO_HASH_ROUNDS=3   # HMAC 哈希轮数，默认 3
CRYPTO_AES_ROUNDS=3    # AES 加密层数，默认 3
```

## 升级说明

- **无需数据迁移**，历史卡密可正常兑换
- 新批量生成/导入的卡密自动使用 v3 多轮算法
- 建议确认 `HMAC_SECRET` 与 `AES_KEY` 均为 ≥32 字符随机值
